# Инструкция для нейросети: факты для брифа «О системе общего образования региона»

Ты — аналитик. На вход получаешь **большую справку о развитии региона в сфере образования и науки** (DOCX или её текст). Твоя задача — **не писать бриф**, а достать из справки факты и вернуть их **одним JSON-объектом** строго по образцу ниже. Текст брифа, суммы, склонения и оформление сделает программа.

## Жёсткие правила

1. **Ответ — только JSON.** Без пояснений до и после, без комментариев внутри.
2. **Ничего не считай и не округляй.** Бери числа так, как они написаны в справке. Суммы (например, «детсады по нацпроекту "Демография" + по нацпроекту "Семья"») считает программа — просто перечисли слагаемые отдельными элементами списка.
3. **У каждого факта поле `q` — дословная цитата из справки** (15–400 символов). **Все числа факта должны стоять внутри его цитаты** — если числа разнесены по фразе, бери цитату длиннее. Копируй символ в символ, не перефразируй. Для строк таблиц (объекты с полем `name`) `q` — название объекта из таблицы в том виде, как оно написано; числа из ячеек этой строки программа найдёт сама.
4. **Числа — числами:** `12137`, а не `"12 137"`; доли — с точкой: `14.19`.
5. **Нет данных в справке → `null`** (для списков — `[]`). Ничего не придумывай и не бери из памяти.
   Поля не пропускай и новых не добавляй: в ответе должны быть **все** поля образца — те, для которых
   данных нет, со значением `null`.
6. Названия регионов: `nom` — именительный («Удмуртская Республика»), `gen` — родительный («Удмуртской Республики»), `prep` — предложный без предлога («Удмуртской Республике»).
7. `manual_additions`, `problems`, `solutions` — **всегда пустые списки**. Их заполняет человек.
8. **Тире — среднее «–»**, а не длинное «—» (дефис в составных словах остаётся дефисом). Это касается текстов в `risks` и `signals`.

## Где что искать в справке

| Поле | Раздел справки | Что взять |
|---|---|---|
| `year` | весь документ | текущий год справки (год кампании, «в текущем 2026 году») |
| `history.kindergartens_built` | 1.2.2 | по элементу на каждый **введённый** блок: НП «Демография» (итог «введены в эксплуатацию N объектов … мест»), НП «Семья», если там что-то **уже введено** («досрочно введен»). Частные детсады и планы — не брать |
| `history.schools_built` | 1.3.2, подраздел о новых местах; «Резервный фонд» в 1.3.3 | НП «Образование» (итог «введены в эксплуатацию N объектов»); уже введённые школы по «Все лучшее детям». Если в итоге сказано «из них N объектов – за счет средств субъекта», добавь элемент с `"part_of_previous": true` и `"note": "за счет средств субъекта Российской Федерации"`. Школа, построенная за счёт резервного фонда Правительства РФ **отдельно** от нацпроекта, — отдельный элемент с `note` и **без** `part_of_previous` |
| `history.schools_repaired` | 1.3.3 «Капитальный ремонт зданий школ» | строка «Всего в период … отремонтировано N зданий школ на M мест»; `since` — первый год периода |
| `history.kindergartens_repaired` | 1.3.3 «Капитальный ремонт … дошкольных» | строка «Всего … отремонтировано N зданий детских садов на M мест» |
| `tochka_rosta`, `aop_mtb`, `computers`, `sport_halls`, `it_cube`, `kvant_school`, `kvant_children`, `kvant_mobile` | 1.3.2, «не относящейся к созданию новых мест» | числа из маркированного списка; если строки нет — `null` |
| `advisors_schools` | 1.3.2 | число **школ** из «в N школах и в K колледжах … советники» |
| `zemsky` | 1.3.2 | два элемента: за 2020–2024 и за последний год; `teachers` — переехало, `young` — до 35 лет |
| `status.dou_*` | 1.2.1 | группы ДОО, воспитанники, доступность, дата отчётности 85-К |
| `status.schools`, `urban`, `rural`, `two_shift`, `three_shift` | 1.3.1 | как в тексте; если трёхсменного режима нет — `"v": 0` |
| `status.gpd` | 1.2.1, абзац о группах продленного дня | текущие значения (не за прошлый год) + `rf_share` — текущее значение по РФ |
| `status.school_repairs_current` | 1.3.3, таблица «Перечень объектов» по школам | **каждая строка таблицы** — элемент: `name` (кратко), `places`, `readiness` (число % или строка «не строится»), `q` |
| `status.school_repairs_next` | та же часть | строка «В {год} году планируется отремонтировать N зданий школ на M мест»; нет — `null` |
| `status.kg_repairs_current`, `kg_repairs_next` | 1.3.3, по детским садам | аналогично |
| `status.construction` | 1.2.2 и 1.3.2 (таблицы объектов), «Капитальные вложения» | **каждый ещё не введённый объект строительства**: `type` = `"school"` или `"kg"`; `program` = `"vld"` («Всё лучшее детям»), `"semya"` («Поддержка семьи»), `"fp_non_np"` (ФП, не входящий в нацпроекты), `"capex"` (капитальные вложения); `year` — плановый год; `readiness` — % или «не строится». Капремонт СПО сюда не относится |
| `status.risks` | сноски и примечания к таблицам | **только явно названные в справке риски** («Высокие риски не завершения работ», ходатайства о переносе сроков). `text` — связная фраза твоими словами, но все числа, названия и реквизиты — из справки |
| `status.camp` | 1.4, «Организация отдыха детей и их оздоровления» | текущий год, **не** значения «за 2025 год». `types.kind`: `stationary` (стационарные/загородные), `day` (с дневным пребыванием), `labor` (труда и отдыха), `tent` (палаточные), `profile` (профильные); нулевые не указывай. `large_families` — только если в справке есть дети из многодетных семей |
| `signals` | весь документ | 3–7 **наблюдений для куратора** (в бриф не попадут): отложенный спрос в детсады, низкое освоение субсидий (<70 %), уменьшение лимитов, переносы сроков, отставание показателя от плана, недостигнутые показатели зарплаты, снижение охвата к прошлому году. `text` — одна фраза, `q` — цитата-источник |
