# Материалы

Папка мероприятия: документы раскладываются по правилам, реестр собирается сам.

Сбросили документы — сервис прочитал каждый, назвал по-человечески и сразу поставил номер:
«Бриф – Создание эталонной системы показателей», «Справка о развитии округа». Жанр документа
стоит первым словом; имя, которое вы дали файлу сами, главнее заголовка внутри него.

Номера идут по старшинству — повестка, список участников, модератор, бриф, общие материалы,
материалы по вопросам — и пересчитываются при каждом изменении. Первые четыре закреплены:
повестка всегда 01, список участников 02, модератор 03, бриф 04, даже если остальных ещё нет
(есть только модератор — он 03). Материалы идут с 05 подряд, и пришедшая позже повестка их не сдвигает.

Первичка остаётся в подпапке `Архив` под теми именами, под которыми пришла; пакет собран из копий.
Документы прилетают и по одному — из мессенджера в «Приёмную», откуда их разбирают по папкам.

Поиск идёт и по тексту внутри документов — мероприятие находится по фразе из справки, а не только
по названию папки.

Подробности для разработки — в [CLAUDE.md](CLAUDE.md), замысел целиком — в [../STORAGE-SPEC.md](../STORAGE-SPEC.md).
