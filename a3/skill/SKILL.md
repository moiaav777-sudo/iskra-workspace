# A3-дашборд из документа

Собрать из документа **один лист A3**, готовый к печати. **По умолчанию
горизонтальный** (`"orientation": "landscape"`). Вертикальный (`"portrait"`) —
только по явной просьбе пользователя. Не выбирать ориентацию молча за него.

Лист описывается как последовательность блоков любого числа и типа —
цифровых (KPI, диаграммы, таблицы) и текстовых (тезис, список, этапы,
хронология, статусы, сравнение, сетка карточек, выводы). Раскладку, ширину,
масштаб шрифта и высоту подбирает движок `assets/a3.js`.

Правила составления JSON — в `PROMPT.md`. Они одинаковы для Claude и для любой
другой нейросети. **Прочитать `PROMPT.md` целиком перед работой.**

Здесь — только то, что добавляется при наличии терминала: сборка PDF и проверки.

## Конвейер

1. **Прочитать документ целиком.** `.docx`:
   ```bash
   python3 -c "import zipfile,re,sys;x=zipfile.ZipFile(sys.argv[1]).read('word/document.xml').decode();x=re.sub(r'</w:(p|tr)>','\n',x);print(re.sub(r'<[^>]+>','',x))" ФАЙЛ.docx
   ```
2. **Составить JSON по `PROMPT.md`**: тип и главная мысль документа → блоки под
   форму содержания → порядок важности и `priority` → сжатие текста.
   Записать в `data.json`. Примеры — `references/example-*.json`.
3. **Собрать и отрендерить:**
   ```bash
   python3 "$SKILL"/scripts/build_kit.py data.json list.html && "$SKILL"/scripts/render.sh list.html
   ```
   `$SKILL` — папка этого файла. Имена `data.json` и `list.html` — одни на сессию.
4. **Прочитать вывод `render.sh`.** Обе строки обязаны быть «ок»:
   `САМОПРОВЕРКА` и `ПРОВЕРКА ФОРМАТА`. Строка с ориентацией, числом блоков и
   масштабом шрифта — справочная; ориентация в ней должна совпадать с запросом.
5. **Открыть PNG инструментом Read и осмотреть.** Автоматика не видит неудачный
   выбор типа блока, пустоты внутри карточек, слипшиеся линии. Поправить JSON,
   повторить 3–5.
6. **Отдать PDF.**

## Как движок подбирает раскладку

1. Каждому блоку две ширины: стандартная и компактная (или `w`, если задана).
2. Блоки жадно укладываются в ряды по 12 колонок; ряд растягивается до 12.
3. Для каждой раскладки двоичным поиском ищется самый крупный масштаб
   `k` ∈ [1,0; 2,0], при котором всё помещается. Берётся раскладка с большим `k`.
4. Не помещается при `k = 1` — включается плотный режим: сжимаются только
   вертикальные отступы, кегли не трогаются.
5. Не помещается и так — ступени уступок, каждая заметнее предыдущей:
   отпустить заданную в JSON ширину `w` → короткие пункты списков и блоков
   состояния в две-три колонки → и то и другое.
6. Не помещается и после этого — лист всё равно собирается: снимается самое
   незначимое, то есть блок с наибольшим `priority` (при равном — который
   ниже), и подбор повторяется. О каждом снятом блоке сообщается; снятие
   блока с `priority` 1 или 2 отмечается отдельно, как потеря.
7. Остаток высоты уходит рядам с диаграммами, без них — всем рядам поровну.
8. Диаграммы рисуются под фактический размер карточек, затем — проверки.

## Если проверка ругается

| Замечание | Что править в JSON |
|---|---|
| не помещается даже при минимальном шрифте | сократить тексты, объединить блоки, пометить второстепенные `priority: 3` |
| снят второстепенный блок | согласиться или сократить остальное |
| в хронологии даты не по порядку | переставить этапы по возрастанию дат |
| шапка и подвал повторяют друг друга | убрать дату или название документа из одного места |
| сняты значимые блоки | лист не вместил всё: сократить тексты или пересмотреть `priority` |
| лист заполнен на N% | добавить содержательные блоки или раскрыть пункты |
| обрезана подпись | сократить подпись (регионы — «обл.», «кр.», «Респ.», аббревиатуры) |
| число не влезает в плашку | округлить, единицу — в `unit` |
| заголовок занимает 4+ строки | сократить до вывода в одну мысль |
| неизвестный тип блока | взять тип из списка в `PROMPT.md` |
| нет источника / заголовка | заполнить `source` / `header.title` |

**Никогда не лечить уменьшением шрифта в CSS.** Пол кеглей — часть контракта.

## Правка оформления

Цвета, шрифт, базовые кегли — в `.sheet` и `:root` файла `assets/a3.css`.
Блоки и диаграммы — `assets/a3.js`. После любой правки пересобрать конструктор:

```bash
python3 "$SKILL"/scripts/build_kit.py
```

## Файлы

| Файл | Что внутри |
|---|---|
| `PROMPT.md` | **инструкция для любой нейросети**: анализ документа, типы блоков, схема JSON |
| `a3-kit.html` | конструктор: один файл, вставил JSON — получил лист |
| `assets/a3.css` | холст, типографика с масштабом, стили всех блоков, палитра |
| `assets/a3.js` | движок раскладки, блоки, диаграммы, самопроверка, разбор JSON |
| `scripts/build_kit.py` | сборка конструктора или готового листа из JSON |
| `scripts/render.sh` | HTML → PDF + PNG, самопроверка и проверка формата |
| `references/example-*.json` | примеры: цифровая справка, текстовая дорожная карта, короткая справка |
| `references/example-*.pdf` | как они выглядят на листе |
| `references/layout.md` | геометрия, масштаб, алгоритм раскладки |
| `references/brand.md` | фирменный стиль и его перенос со слайдов на A3 |
