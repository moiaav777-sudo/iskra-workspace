# A3-дашборд из документа

Превращает структурированный документ в **один лист A3**, готовый к печати.
По умолчанию лист **горизонтальный**; вертикальный — полем
`"orientation": "portrait"` или просьбой к нейросети. Подходит и для цифровых документов, и для текстовых:

- справка или отчёт с показателями → KPI, диаграммы, выводы;
- план мероприятий, дорожная карта → цель, хронология, статусы, ответственные;
- положение, регламент → назначение, этапы процедуры, требования, сроки;
- протокол, решение → ключевые решения, поручения;
- аналитическая записка → главный вывод, сравнение вариантов, предложения.

**Раскладка динамическая.** Блоков может быть 3, 7 или 12. Лист сам решит, как
их разложить по рядам, и подберёт размер шрифта: мало содержания — крупнее,
много — плотнее, но не мельче читаемого.

**Работает с любой нейросетью**: ChatGPT, Claude, Gemini, GigaChat, YandexGPT,
DeepSeek. Нейросеть разбирает смысл документа и выдаёт данные в JSON, а
вёрстку делает браузер. Ни программ, ни интернета не нужно.

## Как пользоваться — любая нейросеть

1. Скопируйте весь текст из `PROMPT.md` в нейросеть.
2. Приложите документ и отправьте.
3. Скопируйте JSON из ответа (можно вместе с лишним текстом — лист разберётся).
4. Откройте `a3-kit.html` в браузере, вставьте JSON в поле внизу и нажмите
   **«Собрать лист»**.
5. Посмотрите на плашку под листом:
   - **зелёная** — всё в порядке;
   - **красная** — замечания. Скопируйте их, отправьте нейросети,
     вставьте исправленный JSON.
6. Печать: **Ctrl+P** (Mac — **Cmd+P**) → «Сохранить как PDF» →
   бумага **A3**, ориентация **альбомная** (или книжная, если лист вертикальный),
   поля **нет**, **«Фоновая графика» включить**.

`a3-kit.html` — один самодостаточный файл: его можно переслать коллеге.

## Правка руками

1. Нажмите **«✏️ Режим правки»** вверху справа — все тексты на листе подсветятся пунктиром.
2. Щёлкните по нужному тексту и исправьте: заголовки, пункты, числа KPI и карточек,
   подписи, выводы, строку источника.
   - **Enter** — готово, **Shift+Enter** — новая строка, **Esc** — отменить правку;
   - выделение жирным сохраняется, лишняя разметка при вставке из Word отбрасывается.
3. Лист сам перестроится под новый текст, плашка проверки обновится. JSON в поле
   внизу обновляется тоже — его можно снова отдать нейросети.
4. **«Скачать HTML»** — файл со всеми правками. Откроется на любом компьютере,
   в нём снова можно править. **«Скачать JSON»** — данные для нейросети.
5. Закрыли вкладку, не скачав файл? При следующем открытии лист предложит
   восстановить правки (хранятся в этом браузере).

Числа внутри диаграмм (длины баров, точки линий) правятся в поле JSON внизу:
найти нужное число и заменить, затем «Собрать лист».

## Как пользоваться — Claude Code

```bash
cp -R a3 ~/.claude/skills/
```

Затем приложить документ и написать `/a3`. Claude составит JSON, соберёт PDF,
прогонит проверки и посмотрит на результат. Нужен Google Chrome, Chromium или Edge.

## Какие блоки бывают

| Блок | Для чего |
|---|---|
| `callout` | главная мысль, цель — крупным шрифтом |
| `kpis` | ключевые числа с изменением к прошлому периоду |
| `text` | пояснение, порядок, условия |
| `list` | перечень, требования, ответственные |
| `steps` | этапы процедуры по порядку |
| `timeline` | события и контрольные точки с датами |
| `status` | мероприятия и поручения: выполнено / в работе / отставание / риск / план |
| `compare` | было и стало, варианты, плюсы и минусы |
| `grid` | равноправные направления, цели, участники |
| `table` | таблица |
| `bar_h`, `bar_v`, `line`, `donut`, `stacked`, `bullet` | диаграммы |
| `conclusions` | выводы, решения, предложения |

Нейросеть подбирает блок **по форме содержания**: этапы — этапами, сроки —
хронологией, цифры — диаграммами. Текст в выдуманные цифры не превращается.

## Как лист подбирает раскладку

1. Блоки укладываются в ряды по 12-колоночной сетке, ряды растягиваются по ширине
   — дыр сбоку не бывает.
2. Пробуются стандартные и компактные ширины блоков, из них выбирается та
   раскладка, где шрифт выходит крупнее.
3. Масштаб шрифта от ×1 до ×2 подбирается так, чтобы содержимое заполнило лист.
4. Если не помещается и при ×1 — сжимаются вертикальные отступы. Шрифт мельче
   не становится никогда: **самый мелкий текст на листе — 10 pt**.
5. Если не помещается и так — снимаются блоки, которые нейросеть пометила
   второстепенными (`priority: 3`), и лист сообщает, какие.
6. Оставшееся место отдаётся диаграммам, а без них — всем рядам поровну.

## Что проверяется автоматически

- содержимое не помещается / лист заполнен меньше чем на 80%;
- снятые второстепенные блоки;
- обрезанные подписи в диаграммах, числа, не влезающие в плашку;
- слишком длинные заголовки, переполненные блоки;
- неизвестные типы блоков;
- нет заголовка или источника.

Автоматика не видит неудачный выбор блока или пустоты внутри карточек —
перед печатью посмотрите на лист.

## Честность данных

- Нейросеть не должна ничего выдумывать: нет в документе — нет на листе.
- Процент, напечатанный в документе, берётся как есть, не пересчитывается
  (иначе получается 44,8% там, где в документе 44,6%).
- Статусы ставятся, только если следуют из документа.
- Внизу листа — источник и дата.

## Оформление: две темы

- **`soft`** (по умолчанию) — мягкая: тонированный лист, белые карточки без рамок,
  приглушённая палитра из брендовых синих, больше воздуха, тонкие скруглённые бары.
  Легче воспринимается при беглом взгляде.
- **`strict`** — строгая брендовая: белый лист, карточки с рамками, насыщенный
  тёмно-синий. Контрастнее — надёжнее для чёрно-белой печати и ксерокопий.

Переключается полем `"theme"` в JSON.

В мягкой теме лист не бывает монохромным: каждый блок — таблица, список,
диаграмма, карточки — получает свой цветовой акцент (полоска сверху, маркеры,
номера, цвет баров) по кругу палитры: синий, зелёный, золотистый, лавандовый,
бирюзовый. Соседние блоки не повторяют цвет. Текстовые блоки распределяют
пункты по всей высоте, поэтому пустот внизу нет. Смысловые цвета из JSON (`orange` — внимание, `red` — проблема)
всегда главнее. Только смысловые цвета — `"colors": "meaning"`.

## Фирменный стиль

Палитра и типографика — из брендбука, перенесённого со слайдов 16:9 на ширину
A3 коэффициентом 0,585. Подробности и два сознательных отступления —
`references/brand.md`. Сменить стиль — правка переменных в `assets/a3.css`,
затем `python3 scripts/build_kit.py`.

## Состав

| Файл | Кому | Что внутри |
|---|---|---|
| `README.md` | всем | это описание |
| `PROMPT.md` | **любой нейросети** | анализ документа, типы блоков, схема JSON, правила |
| `a3-kit.html` | **всем** | конструктор: вставил JSON — получил лист |
| `SKILL.md` | Claude Code | конвейер со сборкой PDF и проверками |
| `assets/a3.css`, `assets/a3.js` | правка оформления | стили и движок раскладки |
| `scripts/build_kit.py`, `scripts/render.sh` | Claude Code | сборка и рендер в PDF |
| `references/example-numeric.*` | всем | цифровая справка: JSON и PDF |
| `references/example-text.*` | всем | дорожная карта без диаграмм: JSON и PDF |
| `references/example-short.*` | всем | короткая справка на 4 блока: JSON и PDF |
| `references/layout.md`, `brand.md` | правка оформления | алгоритм раскладки, перенос брендбука |

JSON старого формата (`kpis` / `zones` / `conclusions`) по-прежнему открывается.

## Ограничения

- Только A3 (горизонтальный или вертикальный), один лист.
- При минимальном шрифте 10 pt на A3 помещается ~10–12 блоков и ~4 000 знаков текста; больше —
  лист предупредит и снимет второстепенное.
- Логотипа на листе нет.
- Нейросеть с маленьким окном контекста может не удержать длинный документ —
  давайте его частями.
