# Инфографика A3 — чат сервиса

Этот чат отвечает только за папку `a3/`. Общие правила и контракт с порталом — в `../CLAUDE.md`,
задачи — в `../TRACK.md` → «A3».

## Что это
Справка, отчёт или план превращается в одностраничный дашборд A3 для печати. Нейросеть выдаёт JSON
по `a3-PROMPT.md`, раскладку, диаграммы и самопроверку делает JS-движок в браузере.

- Исходники движка: `skill/assets/a3.js`, `skill/assets/a3.css`; сборка `skill/scripts/build_kit.py` → `a3-kit.html`.
- Скилл Claude `/a3` — это `skill/` (на него ссылается ~/.claude/skills/a3, папку не переименовывать).
- Брендбук: `skill/references/brand.md`, раскладка: `skill/references/layout.md`, примеры: `примеры/`.
- `a3-kit.html` и `a3-PROMPT.md` в корне обновляет `build_kit.py` при каждой сборке; их берут `portal/ops/deploy.sh` и стенд — не удалять и не переименовывать.
- Примеры в `примеры/` только на демо-данных.

## Как попадает в портал
Сейчас портал сам отдаёт `a3-kit.html` по адресу https://workspace.example.ru/a3/.
Обновить лист на сайте: пересобрать `a3-kit.html`, закоммитить и попросить общий трек выполнить
`portal/ops/deploy.sh`, либо выполнить самому, отметившись в `../TRACK.md` → «Выкладка сейчас».

## Библиотека листов и разбор справки «Искрой»
Это уже серверная часть. Её делаем отдельным сервисом в `a3/service/` по контракту из `../CLAUDE.md`:
вход из заголовков X-Portal-* с секретом, относительные адреса, журнал через /internal/audit, /healthz.
Порт и подключение к nginx, туннелю и задачам на ПК запросить у общего трека в `../TRACK.md`,
самому их не настраивать.

Решено с пользователем 17.09.2026:
- новая версия листа создаётся по кнопке «Сохранить», а не на каждую правку;
- папок и тегов нет, достаточно поиска и сортировки по дате;
- PDF печатается из браузера, Chrome на сервере не нужен;
- результат работы — редактируемый HTML, как сейчас.

Справку можно загрузить файлом Word (.docx, .doc), Excel (.xlsx, .xls), PowerPoint (.pptx, .ppt), PDF, .rtf, .odt, .txt, .md, .csv — формат по содержимому, чтение `service/app/extract.py` на общем модуле `service/app/docs_common.py` (копия `portal/shared`, здесь не править; решение пользователя 05.10; PDF — pdftotext, без неё — PyMuPDF).

«Приложить к совещанию» (`service/app/static/library.js`): папка пакета — через `link` «Материалов» по ключу совещания; `folder` из «Совещания» — подсказка (404 на загрузке — одна перепривязка и повтор; пользователь 02.10, скриншот A3).

## Нельзя
- Трогать `../portal`, `../moderator`, `../brief`, VPS, туннель, задачи планировщика на ПК.
- Хранить в `a3/` реальные справки сотрудников и ключ «Искры».
- Ломать работу `a3-kit.html` без интернета: он должен открываться и как отдельный файл.
