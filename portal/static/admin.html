Ключ Искры

Один ключ на всё пространство: портал («Спросить Искру»), «Совещание», «Бриф», A3, «Тезисы», «Транскрибатор» и «Объективки». После замены он сразу начинает работать везде, перезапуск не нужен.

Дата из окна «API-ключи» в Искре. Ключ там живёт от 7 до 365 дней, по умолчанию 30, и Искра сама срок не сообщает — за неделю до конца портал предупредит на главной, здесь и в суточном отчёте. При выпуске ключа выбирайте 365 дней.

Сначала выпустите новый ключ в кабинете Искры, вставьте его сюда вместе с датой окончания, затем отзовите старый.

Расход

Считается по журналу: сервис записывает расход вместе с самим действием. Видно только то, что сервисы успели сообщить.

Почта для учётных данных

С этого ящика новый сотрудник получит адрес портала, логин и временный пароль. Удобнее завести отдельный ящик, например на Яндексе.

Не пароль от ящика, а отдельный пароль для программ: Яндекс ID → «Безопасность» → «Пароли приложений» → «Почта». Если пароль уже сохранён, поле можно оставить пустым.

Загрузить списки участников

Выберите один или несколько файлов Word (.docx). Портал найдёт людей и покажет их здесь — ничего не запишет, пока вы не проверите и не нажмёте «Добавить отмеченных». Повторы между файлами сливаются; кто уже есть в реестре — отмечен.

Удалить ?

Учётная запись удалится насовсем: войти по ней будет нельзя, вернуть её тоже. Журнал и документы, которые человек сделал, останутся с его логином.

Если человек может вернуться, лучше «Заблокировать» — это обратимо.
