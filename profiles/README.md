# Объективки

Сервис портала workspace.example.ru: краткая справка о человеке на одну страницу A4 в Word.
Адрес `/profiles/`, порт **8990** на 127.0.0.1 (стенд 8991). Подробности — `CLAUDE.md`.

- **По имени** — «Искра» ищет в официальных открытых источниках и даёт ссылки.
- **По справке** — сведения только из приложенного документа (Word, Excel, PowerPoint, PDF, .rtf, .odt, .txt, .md, .csv) (по желанию — дополнить из открытых
  источников); фото — первая картинка Word.
- Карточка правится на экране; фото загрузить/заменить/убрать; «Пересобрать Word» подбирает кегль
  и интервал, чтобы уложиться в одну страницу, иначе предупреждает.
- «Объединить объективки» (2–10, из реестра и файлов) и «Переработать и объединить» (до 10 документов
  о людях → карточки → один файл): содержание по фамилиям с гиперссылками и номерами страниц.
- «Приложить к мероприятию» — в папку пакета мероприятия у «Материалов».

```
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests -q
PROFILES_DEV=1 .venv/bin/python -m uvicorn app.main:app --port 8991
```

Ключ «Искры» сервис не хранит: портал пишет `ISKRA_API_KEY` в `<PROFILES_HOME>/.env`.
